# Verify and upload

**Verify** compiles the sketch. **Upload** compiles it and writes it to the board.

Progress and results appear in the Sketch view. Compiler errors are listed there and in the **Problems** panel; select one to go to the line.

If the board package for the selected board is not installed, the Sketch view links to it in **Boards and Tools**.

Shortcuts: **Verify** `Ctrl+Alt+R` (macOS `Cmd+Alt+R`), **Upload** `Ctrl+Alt+U` (macOS `Cmd+Alt+U`).
