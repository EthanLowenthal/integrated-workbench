# Sketches

A sketch is a folder that contains an `.ino` file with the same name, for example `Blink/Blink.ino`. It can also contain `.cpp` and `.h` files, which are compiled with it.

Integrated Workbench works with the sketch of whichever file is open in the editor. Its settings are stored in `sketch.yaml` inside the sketch folder, the same file arduino-cli and Arduino IDE 2 use, so a sketch opens the same way in either.
